【押金类 = 方向敏感型】核心矛盾在"钱往哪走"，必分场景 + 毒药词。
- 绝对拦截场景：①供应商主动付款（主体反转，拦截）②退款/扣款推演陷阱（拦截）③履约保证金混淆（一票否决）④自然人行为（拦截）。
- 核心匹配场景：正向支付（甲方付给供应商）、反向退还（退到约定账户）。
- poison_words：当条款含"无理由退款/全额退还"等方向反转语义时填，否则留空。
- reasoning_chain：找动作实体 → 判断资金方向 → 核对收款主体 → 决策。
- logic 示例（≤120字）："出现'供应商向甲方付款'即资金方向反转，与押金本义相悖，命中即放弃。"

【封顶/保底类 = 数量承诺型】核心矛盾在"是否构成刚性承诺"。
- poison_words：不少于 / 不低于 / 保底 / 最低消费 / 至少 / 承诺采购达（一票否决，最高优先级）。
- 绝对拦截场景（负向排除）：非采购承诺、固定总价、据实结算、保底兜底、规格限制、责任罚款、员工福利、合同总金额、非结算承诺、预测兜底。
- 核心匹配场景：上限封顶（金额不超过某阈值）。
- reasoning_chain：扫毒药词 → 判刚性承诺边界 → 区分"上限"与"保底下限" → 决策。

【违约金类 = 普通匹配型，无毒药词】核心矛盾简单，无需一票否决。
- poison_words：[] （违约金无方向反转、无刚性承诺陷阱，留空）。
- 绝对拦截场景：与"定金/赔偿金/罚款"混淆。
- 核心匹配场景：违约触发条件 + 违约金计算方式。
- reasoning_chain：识别违约行为 → 匹配责任条款 → 排除相邻概念 → 决策。

【元判断口诀】先问三句：钱的方向敏感吗？（分场景+方向毒药词）有刚性数量承诺吗？（保底类毒药词）都没有吗？（普通匹配，poison_words 留空）。判定完再落规则。
